# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [Unreleased]

## [0.2.0] - 2026-08-21

### Added

- SARIF 2.1.0 output for CI and code-scanning workflows.
- Versioned JSON project release policy configuration.
- Android release network-security auditing, including nested domain-config inheritance and safe fail-closed XML handling.

## [0.1.0] - 2026-08-21

### Added

- Local-first `scan`, `apk`, `endpoints`, `compare`, and experimental `icp` commands.
- Text, JSON, and Markdown reports with documented exit codes.
- Capacitor, Gradle, endpoint, APK signature, and public certificate safety rules.
- Node.js 20/22 CI matrix and a non-publishing release artifact workflow.
- Synthetic automated tests and public security/governance documentation.
