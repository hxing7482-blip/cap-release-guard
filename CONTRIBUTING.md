# Contributing

Thank you for contributing to `cap-release-guard`.

1. Work only with public-safe, synthetic fixtures.
2. Never submit credentials, signing keys, proprietary APKs, private certificates, or confidential paths.
3. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before opening a pull request.
4. Keep changes focused and document user-visible behavior.
5. Add or update tests for every rule change.

By contributing, you agree that your contributions are licensed under Apache-2.0.
