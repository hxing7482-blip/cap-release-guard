# cap-release-guard

Catch unsafe Android and Capacitor release mistakes before they ship.

`cap-release-guard` is an independent, local-first Android and Capacitor production release safety auditor.

Version 0.1.0 is under active development.

## Security model

`cap-release-guard never needs Android private signing keys.` It is designed to run locally without telemetry, uploads, cloud services, or a database.
